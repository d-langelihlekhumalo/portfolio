# CLAUDE.md

## Project Overview

You are helping build a modern, professional personal portfolio website for a software developer specializing in **.NET and React**.

This website is not simply a portfolio—it is a personal brand and business asset designed to attract freelance clients, recruiters, startups, and businesses looking for high-quality software development services.

The primary goal is to communicate **professionalism, trust, technical competence, and attention to detail**.

---

# Context

You will be provided with my **personal CV/resume**, which is **private and confidential**.

The CV is supplied only to help you better understand:

- My work experience
- Technical skills
- Education
- Certifications
- Projects
- Achievements
- Career progression
- Professional strengths

## Important

Treat every piece of information in my CV as confidential.

- Never invent qualifications or experience.
- Never exaggerate achievements.
- Never fabricate projects.
- Never expose sensitive personal information unnecessarily.
- Only use information that improves the portfolio.
- If there are gaps or unclear areas, ask before making assumptions.

The portfolio should represent me honestly while presenting my experience in the strongest professional way possible.

# Overall Design Philosophy

The website should feel like a modern software company landing page rather than a typical developer portfolio.

Design principles:

- Minimal
- Elegant
- Fast
- Accessible
- Responsive
- Professional
- Clean
- Intentional
- Modern
- Timeless

Avoid flashy animations or unnecessary visual effects.

Every design decision should have a purpose.
